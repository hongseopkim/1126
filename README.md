# 1126 · SCK Work Guide

임시 행사 운영 안내 웹앱입니다. 행사 담당자별 업무 안내와 행사 운영 데이터 검색을 제공합니다.

## 접속

- 앱: https://hongseopkim.github.io/1126/
- 비밀번호: 운영자가 행사 관계자에게 별도로 전달
- Google 계정 로그인 없이 접속
- 비밀번호 입력 후 담당자 선택, 현재 업무, 이전/다음 업무, 타임라인, 챗봇 검색 사용

## 데이터

- `data.enc.json`은 행사 데이터 스냅샷을 AES-256-GCM으로 암호화한 파일입니다.
- 브라우저에서 입력한 비밀번호로 PBKDF2-SHA256 키를 유도해 복호화합니다.
- 데이터 스냅샷에는 담당자별 업무분장, 내빈 명단, 행사일정, 물품, 업체, 케이터링, 홍보 등 공개 허용 범위의 정보가 들어 있습니다.
- 연락처·이메일·차량번호·주민등록번호 패턴은 마스킹한 뒤 암호화했습니다.
- 원본 Google Sheet는 앱에서 직접 읽지 않습니다. Google Sheets 브라우저 교차 출처 정책과 회사 전용 공유 권한 때문에 비로그인 공개 앱에서 직접 조회할 수 없기 때문입니다.
- 따라서 앱 새로고침은 현재 암호화 스냅샷 파일을 다시 읽습니다. 원본 시트 변경사항은 스냅샷을 다시 생성해 배포해야 반영됩니다. 실시간 동기화라고 간주하면 안 됩니다.

## 보안 한계

- 4자리 비밀번호는 행사 관계자에게 간편히 안내하기 위한 임시 접근 장벽입니다. 서버 측 인증이 아니며, 공개 GitHub Pages의 정적 코드와 암호화 파일을 대상으로 충분한 시간과 도구를 가진 공격자가 오프라인 추측을 시도할 수 있습니다.
- 민감한 연락처·개인정보 또는 장기 보관 자료를 보호하는 용도로 사용하지 마세요.
- 행사 종료 후 GitHub Pages와 공개 저장소의 암호화 데이터 파일을 비공개/삭제하고, 공개용 Google Sheet 사본의 공유 권한도 회수하세요.

## 배포

## Temporary operation

- 행사 당일에는 PIN 입장 화면과 암호화된 행사 데이터 스냅샷을 사용합니다.
