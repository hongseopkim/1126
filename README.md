# 1126 · SCK Work Guide

개인별 행사 업무를 시간순으로 안내하고, 공개용 Google 스프레드시트 전체 탭을 검색하는 모바일 우선 웹앱입니다.

## 핵심 동작

- 별도 앱 로그인 없이 링크로 접속
- `전체시나리오 및 업무분장` 탭에서 담당자 이름 자동 추출
- 현재 시각과 행사일(2026-11-26)을 기준으로 현재/다음/완료 업무 판정
- A안(현재 업무 집중형)과 B안(전체 타임라인형) 전환
- 이전/다음 업무 이동, 장소 및 원본 주의사항 표시
- 내빈, 행사일정, 물품, 업체, 케이터링, 홍보 등 공개용 탭 통합 검색
- 연락처, 전화번호, 이메일 및 주차 차량정보는 공개 데이터에서 제외 또는 마스킹
- 앱을 열어 둔 동안 60초마다 자동 새로고침, 수동 새로고침 제공
- 모바일 홈 화면 추가를 위한 PWA manifest

## 데이터 연결 방식

- 원본 스프레드시트는 수정하지 않습니다.
- `1126 앱 공개 데이터` 스프레드시트가 원본의 공개 허용 탭을 `IMPORTRANGE`로 참조합니다.
- 공개 데이터 시트는 `sc.or.kr` 도메인 읽기 권한으로 공유합니다.
- 앱은 Google Visualization read endpoint를 사용해 브라우저에서 공개 데이터 시트를 읽습니다.
- 앱은 데이터를 별도 서버나 데이터베이스에 저장하지 않습니다.
- 별도 앱 OAuth 로그인은 없으며, Google Workspace 도메인 공유 권한이 적용됩니다. 회사 계정으로 로그인된 브라우저에서 사용해야 합니다.
- 연락처와 이메일은 검색 결과에서 제외하고, 공개 데이터 복사본에서도 마스킹합니다.

## 배포

- 저장소: https://github.com/hongseopkim/1126
- 앱 주소: https://hongseopkim.github.io/1126/
- GitHub Actions가 `main` 브랜치 변경 시 GitHub Pages를 자동 배포합니다.

## 갱신

- Google Sheets 원본 변경 내용은 공개 데이터 시트의 `IMPORTRANGE`를 통해 반영됩니다.
- 앱은 60초마다 공개 데이터 시트를 다시 읽고, 수동 새로고침도 지원합니다.
- 서비스 워커는 앱 HTML과 설정 파일을 네트워크 우선으로 갱신하여 오래된 화면이 남지 않도록 합니다.
