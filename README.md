# 1126 · SCK Work Guide

임시 행사 운영 안내 웹앱입니다. 행사 담당자별 업무 안내와 행사 운영 데이터 검색을 제공합니다.

## 접속

- 앱: https://hongseopkim.github.io/1126/
- 비밀번호: 행사 관계자에게 별도로 전달
- Google 계정 로그인 없이 접속
- 비밀번호 입력 후 담당자 선택, 현재 업무, 이전/다음 업무, 타임라인, 챗봇 검색 사용

## 챗봇 검색 구성

- 내빈 명단: 소속·이름 2열 표, 소속 기준 정렬
- 주차 안내: 실제 등록 차량번호 목록과 원본 업무분장에 명시된 주차 위치 안내
- 케이터링: 업체명과 음료·다과·기타 전체 품목을 카드로 표시
- 물품리스트 탭은 앱 검색 및 표시 대상에서 제외

## 데이터

- `data.enc.json`: 개인별 업무분장 및 기존 행사 운영 데이터 스냅샷
- `data-special.enc.json`: 내빈, 주차 등록 차량, 주차 안내, 케이터링의 정리된 데이터
- 두 파일 모두 AES-256-GCM, PBKDF2-SHA256(1,200,000회)로 암호화되며 브라우저에서 입력한 PIN으로 복호화합니다.
- 연락처와 이메일은 표시·검색 대상에서 제외합니다. 주차 차량번호는 행사 운영 확인을 위해 표시합니다.
- 원본 Google Sheet는 앱에서 직접 읽지 않습니다. 따라서 앱 새로고침은 현재 암호화 스냅샷을 다시 읽습니다. 원본 시트 변경사항은 스냅샷을 다시 생성해 배포해야 반영됩니다.

## 보안 한계

- 4자리 PIN은 행사 관계자에게 편리한 임시 접근 장벽입니다. 서버 측 인증이 아니며, 공개 GitHub Pages의 암호화 파일을 대상으로 오프라인 추측 공격을 받을 수 있습니다.
- 주차 차량번호 등 개인정보가 포함되므로 행사 관계자에게만 PIN을 전달하고, 행사 종료 후 Pages와 암호화 데이터 파일을 폐쇄·삭제하세요.
